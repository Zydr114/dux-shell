# Clavis 整合交付与验收记录

日期：2026-10-31。开发分支：`feat/clavis-integration`。实现提交：`31e888601`（共享频谱）、`0c51d6e1a`（播放器、灵动岛、卡片及设置）。调研基线和范围见 [整合方案](clavis-integration-research-plan.md)。

## 已实现

- 完整播放器：圆角、Caelestia、渐隐背景三种封面，Wave / Material 两种进度条，主题 / 封面两种配色，共 12 种组合。包含真实 45 段输入汇聚的 36 柱频谱、九瓣封面、播放器选择、随机、上一首、播放暂停、下一首和三态循环。歌词、音量、输出设备和键盘操作复用 DMS 服务。
- 媒体弹出宿主：Clavis 的内容尺寸为 `540×210` / `640×240`，灵动岛另计把手；脱离仪表盘最少行数约束。受屏幕可用区域限制，窄卡先预留完整控制区再缩小或收起封面，受限高度可滚动。Material II 也使用独立媒体宿主。
- 灵动岛：曲名、歌词、曲名加歌词三种模式；时间可与歌词及附属 OSD 同时显示。附属 OSD 有独立单次超时，展开媒体时位于把手栏，保留当前页面和焦点。明确点击主页的音量/亮度入口仍打开可交互滑块。
- 通知：细条绑定实际到期时间；Controller 拥有展示期时停止 wrapper 的另一计时器。悬停暂停、移开续期、去重更新、持久通知及销毁交还计时均有对应处理。
- 卡片：Cookie 模拟钟及表盘/指针/日期选项、日期卡、媒体、电池、CPU、内存、网络、磁盘和天气外观。保留可编辑网格和原有服务；日期卡可进入现有日历。天气页的 Hero、预报卡和图表共享外观选择。
- 常驻开销：共享一个 cava，保留六段旧接口，按消费者切换 6 / 45 段。不可见、停止播放、全局关闭可视化或减少动态效果时释放对应采样；装饰动画遵守可见性及动态效果设置。没有新增后台歌词进程、天气轮询或常驻配置监视器。

实现采用 DMS 控件、服务和现有形状数据独立编写。参考 Clavis 固定快照 `c3ee54f147d5e85db072573857a83ca949a317a0` 的截图、功能和设置含义，没有复制其 GPL QML 或 native 模块。

## 设置入口

进入 **设置 → 仪表盘**：

1. **Clavis reference appearance** 应用 `clavis + caelestia + material + theme`。
2. **Import Clavis media appearance** 的刷新按钮按需读取 `$XDG_CONFIG_HOME/clavis/config.json`，展示封面、进度、配色预览后，勾号应用。只合并四个媒体字段；其他媒体选项、其他页面和未知字段保留。非法或缺失值不会应用，不持续监视 Clavis 文件。
3. 媒体选项中可分别修改播放器、Clavis 封面、Clavis 进度和封面取色。歌词、设备名称等沿用既有选项。
4. **Apply Clavis card styles** 修改现有卡片外观，不写入 `dashCards`，不改变卡片位置和尺寸。日期卡需要从仪表盘编辑模式添加。
5. **Audio visualizer** 控制频谱及 Caelestia 封面运动；本机最终保持原有的全局关闭选择，需要动态效果时手动开启。

进入对应状态栏的灵动岛设置，选择媒体文字模式、媒体最大宽度、附属/替换 OSD 及通知倒计时。已有实例保存的选择继续优先。悬浮球保留原来的瞬时活动呈现。

本机已使用 Clavis 参考播放器和卡片样式，以及时间/曲名加歌词/附属 OSD。最后一轮临时九卡网格已撤回，恢复进入该轮验收时的网格；没有将示例布局作为新的默认值。设置原始备份和最终设置位于 `~/.local/state/dms/backups/clavis-20261031/`，未提交个人配置。

## 资源检查

使用同一运行会话，对每阶段等待后采样两秒；CPU 以一个核心为 100%，内存是整个 Quickshell 进程 RSS。测试时还运行用户桌面应用。这是有限场景记录，不是与旧版本的 A/B 基准，也不是长期泄漏检验。

| 场景 | CPU | RSS MiB | cava 数量 |
| --- | ---: | ---: | ---: |
| 展开，频谱关 | 18.0% | 757.11 | 0 |
| 展开，频谱开 | 24.5% | 759.23 | 1 |
| 收起，既有条形可视化开 | 5.0% | 759.76 | 1 |
| 收起，减少动态效果 | 2.5% | 754.95 | 0 |
| 收起，可视化关 | 3.5% | 754.29 | 0 |
| 人工来源全部暂停 | 2.0% | 754.52 | 0 |

展开时波浪进度仍持续动画，全局频谱关闭不等于所有播放动画停止；减少动态效果可关闭这类运动。测试也用实际声音输入观察了环形频谱。记录见 [资源样本](evidence/clavis-20261031/resource-samples.json)。结束后已清理人工播放器和声音进程，关闭可视化时没有遗留 cava。

## 尚未覆盖及已知问题

- 鼠标拖动、悬停暂停与连续 OSD 并发、实际输出设备切换、Raise、无控制能力来源、活动通知中热重载、多屏/竖栏和其他 compositor 尚未完整手工验收。源码门控和纯逻辑测试不替代这些操作。
- 紧凑通知占据岛时不另绘附属 OSD；通知活动和期限不受该短暂 OSD 状态影响。时间、歌词和 OSD 并存覆盖主页/媒体紧凑态。
- 临时替换并恢复仪表盘布局时，未改动的 `DashCardGrid.slotLayout` 仍可发出 binding loop。现有日志不足以确定依赖链或归因；没有把它描述成已解决。另有本机缺少 `khal` 的日历集成警告。最终媒体矩阵和键盘操作日志没有新增 QML 警告；卡片场景保留上述问题。
- 天气服务未提供 AQI、昨天实况、气候标准线，网络/磁盘卡使用服务真实汇总数据；没有添加无数据支撑的示意值。实时天气不可用时保留缺失状态。
- 当前视效与 Clavis 的输入源、字体、主题及采样平滑不同；12 项设置和主要交互已实现，不承诺跨项目逐像素或逐帧一致。
